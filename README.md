# my-angular-hub

Application Angular qui centralise leçons et exercices d'apprentissage d'Angular.

## Stack

- [Angular 22](https://angular.dev/)
- [Angular CLI](https://angular.dev/tools/cli)
- TypeScript
- [Vitest](https://vitest.dev/)
- [Bun](https://bun.sh/)

## Installation

```bash
git clone https://github.com/kdauvergne/my-angular-hub.git
cd my-angular-hub
bun install
```

## Scripts

```bash
bun run start
bun run build
bun run watch
bun run test
```

## Contenu

- **Leçons** : notions clés d'Angular
- **Exercices** : mises en pratique associées à chaque leçon
