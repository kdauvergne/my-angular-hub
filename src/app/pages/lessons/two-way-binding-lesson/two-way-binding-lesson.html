🏛️ Du MVC au MVVM

Pattern MVC (Traditionnel)

Model - View - Controller

  • Le Contrôleur intercepte les événements de l'utilisateur.
  • Il met à jour manuellement le Modèle.
  • Il doit redemander explicitement le rafraîchissement du DOM.
  • Inconvénient : Manipulation verbeuse du DOM.

Pattern MVVM (Façon Angular)

Model - View - ViewModel

  • Model : Données brutes de l'application (API / Services).
  • View : Le template HTML de votre composant.
  • ViewModel : La classe TypeScript liant la vue et le modèle.
  • Avantage : La synchronisation est 100 % automatique !

🍌 "Banana in a Box" : [(ngModel)]

La syntaxe [()] combine la parenthèse (Event) dans le crochet (Property) :

  • 🟦 [ngModel] : Property Binding (Met à jour le champ si le TS change).
  • 🟧 (ngModelChange) : Event Binding (Met à jour le TS si le champ change).
