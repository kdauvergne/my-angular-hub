⚙️ 1. Configuration & Architecture Service

Étape A : Activer HttpClient

app.config.ts

Avant toute injection, enregistrez provideHttpClient(withFetch()) dans les providers globaux de l'application.

Étape B : Isoler les appels dans un Service

inject(HttpClient)

Ne placez jamais vos URL d'API directement dans les composants. Centralisez les méthodes get<T>() et post<T>() dans un service injectable.

📡 2. Consommer l'Observable dans un Composant

Approche .subscribe() + Signals

Contrôle fin

Idéale lorsque vous devez piloter finement un indicateur de chargement (isLoading), afficher une alerte d'erreur ou déclencher l'appel au clic.

Approche Déclarative : toSignal()

Moderne

Pour un affichage direct en lecture seule, toSignal() convertit l'Observable HTTP en Signal réactif sans écrire de .subscribe().

🎯 Bonnes pratiques en entreprise

1. Désabonnement automatique Un appel HttpClient émet une seule réponse puis appelle automatiquement .complete(). Aucune fuite mémoire n'est à craindre sur une requête HTTP simple.
2. Typage générique strict Précisez toujours le type attendu (http.get<User[]>(...)) plutôt que any afin de sécuriser vos templates et détecter les erreurs à la compilation.
3. Intercepteurs (Interceptors) Pour injecter un token d'authentification (JWT) ou gérer les erreurs 401/500 globalement, utilisez withInterceptors([...]) dans provideHttpClient().
