🔗 Property Binding vs Attribute Binding

Angular permet de lier dynamiquement les données du composant au template HTML via deux approches distinctes :

  • Property Binding [property]="valeur" : modifie directement la propriété de l'objet DOM (recommandé et plus performant).
  • Attribute Binding [attr.attribut]="valeur" : modifie l'attribut du HTML rendu (pour ARIA, SVG, ou attributs de données personnalisés).

1️⃣ Property Binding (DOM)

A. Liaison d'image avec [src]

Source actuelle : {{ imageUrl }}

B. Désactivation conditionnelle avec [disabled]

C. Textes indicatifs avec [placeholder]

2️⃣ Attribute Binding (HTML / Accessibilité / Data)

Si l'élément HTML ne possède pas de propriété DOM équivalente (ex: attributs d'accessibilité ARIA ou attributs data-*), il faut utiliser le préfixe [attr.].

Rendu visuel :

aria-label="{{ ariaLabel }}" | data-custom="{{ customAttr }}"

💡 Quand utiliser quoi ?

  • Property : Propriétés standards ([src], [disabled], [value]).
  • Attribute : Attributs spécifiques ([attr.aria-*], [attr.colspan], [attr.data-*]).

✅ Règle d'or

Privilégier systématiquement le Property Binding lorsqu'une propriété DOM existe, car Angular met à jour directement le nœud du DOM sans ré-analyser l'arbre HTML.
