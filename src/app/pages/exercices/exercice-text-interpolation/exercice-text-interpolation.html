Exercice : Interpolation de texte

Affichage de variables de différents types avec la syntaxe

1. Types primitifs

  • Note maximale : {{ maxScore }}
  • Score actuel : {{ currentScore }}
  • Pourcentage : {{ (currentScore / maxScore) * 100 }} %

2. Objet et méthodes

  • Rôle : {{ user.role }}
  • Nom complet : (méthode) {{ user.getFullName() }}
  • Statut : {{ user.isLoggedIn ? 'Connecté' : 'Déconnecté' }}

3. Tableaux

  • Première compétence (skills[0]) : {{ skills[0] }}
  • Toutes les compétences (.join) : {{ skills.join(' • ') }}
